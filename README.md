## Featured Projects

### 📜 Ancient Scroll Reconstruction using 3D Deep Learning

Volumetric papyrus-surface segmentation for the **Kaggle Vesuvius Challenge**. Tackled the challenge of reconstructing ancient text from high-resolution 3D CT scans of carbonized scrolls.

**Problem:** Segment readable ink surface from noisy 3D volumetric data with sparse ground truth labels.

**Approach:** 
- Built and compared 3D U-Net and SegFormer architectures
- Implemented mixed-precision training for efficient GPU memory usage
- Applied topology-aware loss functions and biased patch sampling
- Ensembled models with test-time augmentation and threshold optimization

**Results:** Improved validation Dice score from 0.25 → 0.68 across 768 high-resolution 3D CT volumes

**Tech:** PyTorch • 3D U-Net • SegFormer • Deep Learning
